# Архитектура Ledger

FastAPI/Pydantic проверяют HTTP-ввод, cookie-сессия определяет владельца. SQLAlchemy управляет транзакциями, Alembic — версиями схемы. PostgreSQL используется в Docker и интеграционных тестах, SQLite — для быстрого локального запуска. JavaScript показывает формы, графики и сравнение периодов; внешних CDN нет.

Десятичный ввод преобразуется через Decimal в целые копейки. Дробные копейки, NaN/Infinity, bool, float и неположительные суммы отклоняются. Transaction и Budget используют BigInteger. SQL SUM остаётся точным целым значением; float используется только для отображаемых процентов. В модели есть владельцы, внешние ключи и уникальный external_id на пользователя.

Отчёт выполняет два GROUP BY-запроса: месяц/вид и категория расходов. В Python попадают только агрегаты, а не операции. Сравнение выполняет два отчёта для равных включительных периодов и считает абсолютную/процентную разницу. PostgreSQL READ COMMITTED не даёт общую snapshot-гарантию между этими запросами. pandas формирует CSV из месячных агрегатов. [Контракт отчётов](REPORTS.md).

CSV-импорт ограничен по размеру и строкам, сначала валидируется, затем выполняется в общей транзакции. Повтор одинакового external_id пропускается, конфликтующее содержимое отклоняется. Ошибка откатывает весь импорт. Бюджеты привязаны к месяцу и категории; расходы считаются по операциям, список последних500 строк не ограничивает агрегаты.

Пароли хешируются scrypt с солью, в БД хранится хеш случайного session token. Cookie HttpOnly/SameSite=Strict, Secure при production; Origin и JSON media type проверяются на изменяющих запросах. Тело ограничено256KiB; in-memory limiter рассчитан на один процесс. Владельцы проверяются сервером, скрытие кнопок не определяет права.

Версии схемы 0001/0002 и безопасное внедрение для исходной базы описаны в [MIGRATIONS.md](MIGRATIONS.md). Для нескольких экземпляров нужен отдельный migration job. Ограничения MVP: нет банковских интеграций, восстановления пароля, общей системы лимитов, нагрузочных гарантий и проверенного аварийного восстановления.
